## Design Specificity Verdict

Authored for this person, decisively — this is no longer category-interchangeable, and the change is structural rather than cosmetic. The prior build was literally another company's design system wearing a CV (HubSpot Canvas tokens, internal colour names preserved, credited in the colophon); this one derives its organizing metaphor from the subject's own work rather than applying a theme to it. The man builds streaming inference at ~2 Hz over never-ending camera feeds with O(1) memory, and the page is shaped like that: a continuous trace measured against a time axis, with a hero graphic that is a signal at rest stepping high at the right end of his name and running off-frame open — a rising edge that never terminates. The two places the metaphor works hardest exist because of problems only this record has: the dash-coded trace key (— published / -- under review / ···· in prep) is an honest, on-metaphor answer to a portfolio whose best work is half-unpublished, and the dedicated author-position column (5/9, 2/3, 1/5) is an academic-CV concern no template handles. The commitment goes deeper than the surface — the graticule's 9px minor division IS the spacing scale (18/27/36/45/54/63/72/90), the fixed 2px bottom rule is simultaneously the page's baseline and the dragon's ground line, orange is quarantined to a single owner by written contract so the sprite reads as an event rather than brand chrome (inverting the prior run's worst failure), and the site ships a size-adjust:132.8% metric-matched fallback face purely so pet.js's Range measurement of the rendered name holds before the webfont swaps. That is an unreasonable amount of specificity spent making one sprite land on one word, and it is exactly the kind of unreasonableness that makes a page unmistakably somebody's. The residue is real but confined: the section spine (About → Work → Publications → Projects → Stack → Recognition) is the standard researcher order, the Stack plate is a tag list in boxes whose flagship-`b` highlighting is arbitrary and whose auto-fit grid visibly ran out of content, the Recognition table is an ungeneric-ed two-column awards list, and the .key buttons are the default portfolio button carrying the primary CTA — the one component that says nothing about instruments. Three generic patches on an otherwise authored page is residue, not foundation; drop a SaaS site or another engineer's CV into this shell and the graticule, gutter, trace key and step-up hero all become meaningless decoration, which is the test.
